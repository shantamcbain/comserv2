3. DRIFT CHECK (read-only; counts, max ids, newest timestamps, column hashes - never row values)
   script/db_drift_check.pl (this branch).
     On the workstation, instance D via the app:
       perl -Ilib script/db_drift_check.pl snapshot --app --label docker3307 --out /tmp/D.json
     On 192.168.1.20, instance N (needs a login Shanta provides, kept in a private my.cnf-style file outside the repo,
     e.g. ~/.native.cnf with [client] user/password/host=127.0.0.1; or sudo mariadb via the unix socket if Shanta approves):
       perl script/db_drift_check.pl snapshot --defaults-file ~/.native.cnf --db ency --label native3306 --out /tmp/N.json
     Compare anywhere:  perl script/db_drift_check.pl compare /tmp/D.json /tmp/N.json
   Notes: --timeout N caps every statement (default 20 s); --checksum is OFF by default because CHECKSUM TABLE reads whole
   tables and was far too slow on production (a run of it did not finish in 3+ minutes) - use it only on a scratch restore.
   Snapshot files are chmod 600 and contain table names/counts only (app_secrets: key NAMES and value LENGTHS).
   Add a nightly run to the daily sweep once both servers are reachable (see section 8).
